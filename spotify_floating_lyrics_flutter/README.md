# elz0mbi33 Flutter

Cross-platform floating Spotify lyrics app.

## Windows release

Download the latest Windows ZIP from GitHub Releases and extract it.

## Local run

```bash
flutter pub get
flutter run -d macos
```

## Spotify setup

1. Create a Spotify developer app.
2. Add this redirect URI:
   - `http://localhost:8888/callback`
3. Open the app and click **Connect Spotify**.
